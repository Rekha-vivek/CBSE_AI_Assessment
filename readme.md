# CBSE AI Assessment

## Project Overview

CBSE AI Assessment is an AI-powered educational application designed to help students access existing questions and generate new practice questions for Class 9 and Class 10.

The application uses Streamlit for the user interface, Supabase for database storage, and the Qwen language model for AI-based question generation.

## Features

- **Question Bank:** Retrieve existing questions from Supabase.
- **Class and Subject Selection:** Select a class, subject, and question type.
- **AI Question Generation:** Generate new practice questions using Qwen.
- **Answer Options and Explanations:** Display multiple-choice options, correct answers, and explanations when provided by the model.
- **Mathematical Formatting:** Display common mathematical expressions using LaTeX formatting.
- **Save Questions:** Store AI-generated questions in Supabase.
- **View Saved Questions:** Retrieve and display previously saved questions.

## Technologies Used

- Python
- Streamlit
- Supabase
- Hugging Face Transformers
- Qwen2.5-1.5B-Instruct

## Installation and Setup

### 1. Clone or download the project

Open the project folder in Visual Studio Code.

### 2. Create a virtual environment

Run the following commands in the terminal:

```bash
python -m venv .venv
```

Activate it on Windows:

```powershell
.\.venv\Scripts\Activate.ps1
```

### 3. Install the required libraries

```bash
python -m pip install streamlit torch supabase transformers
```

### 4. Configure Supabase

Create a Supabase project and configure the following tables:

**`question_bank`** — stores existing questions and their options.

**`generated_questions`** — stores questions generated by the AI.

The application expects the generated-question table to contain the columns `id`, `class`, `subject`, `question_type`, `question_text`, and `created_at`, with suitable data types and defaults.

### 5. Configure environment secrets

Create a file named `.streamlit/secrets.toml` and add your Supabase project URL and publishable key:

```toml
SUPABASE_URL = "YOUR_SUPABASE_PROJECT_URL"
SUPABASE_KEY = "YOUR_SUPABASE_PUBLISHABLE_KEY"
```

Replace the placeholders with your actual values.

**Security:** Never commit `secrets.toml`, passwords, or secret/service-role keys to a public repository. Keep `.streamlit/secrets.toml` in `.gitignore`.

### 6. Run the application

From the project root, execute:

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Open the local URL displayed in the terminal, usually `http://localhost:8501`.

The first AI generation may take longer because the Qwen model needs to be downloaded and loaded. CPU inference can also be slow.

## How to Use the Application

1. Open the application in your browser.
2. Select the class, subject, and question type.
3. Click **Load Sample Questions** to retrieve existing questions.
4. Click **Generate New Question** to generate a practice question using AI.
5. Review the question, options, answer, and explanation.
6. Click **Save Generated Question to Supabase** to store the question.
7. Click **View Saved Questions** to retrieve previously saved questions.

## Important Notes

- The application generates practice material; generated questions are not necessarily official CBSE questions.
- AI-generated answers may contain mistakes. Verify questions and answers before using them for assessment.
- The available classes and subjects depend on the selections configured in the application.
- Supabase table schemas and access policies must match the application's queries and insert operations.
- Model performance depends on available system resources, particularly CPU and GPU memory.
